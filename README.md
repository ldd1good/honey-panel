AutoCAD 的**悬浮命令面板**：把常用命令摆成一片按钮，Ctrl+中键一按就出来。两种布局——环形蜂窝、网格条；每个按钮绑一条 CAD 命令，点一下直接执行，不用敲命令名。

**一份 DLL 覆盖 AutoCAD 2013~2027**（2014 / 2025 实测通过），32/64 位通用，单文件无外部依赖。

| 文件 | 说明 |
|---|---|
| `HoneyPanel.dll` | 下载后直接使用，不需要改名 |

## 安装

1. 下载 `HoneyPanel.dll`，放进**任意目录**（没有固定路径要求，自己能找到就行）
2. CAD 里 `NETLOAD` 选这个文件，命令行出现「蜂窝面板独立插件已加载」
3. 按 **Ctrl+中键** 呼出面板

`NETLOAD` 一次就写入自动加载，以后开 CAD 自动带出来。

> 建议选定一个目录后别再挪动——配置文件 `蜂窝面板.json` 按 DLL 所在目录读写，换了目录等于换一套配置。

## 命令

| 命令 / 操作 | 作用 |
|---|---|
| `HONEYUNLOAD` | 卸载：删自动加载键 + 摘钩子 + 关面板。重启 CAD 后彻底退出，重新 `NETLOAD` 即恢复 |
| **Ctrl+中键** | 呼出面板（快捷键可在设置窗里改） |
| 面板中心「设置」钮 | 打开设置窗 |

<details><summary><b>功能</b></summary>

**布局**
- 环形蜂窝：六边形绕圈排布，三形态（隐藏 / 常驻面板 / 常驻中心）——隐藏时靠 Ctrl+中键呼出
- 网格条：横向排列，**恒常驻**，不占呼出快捷键
- 设置窗里随时切换，两种布局各自记住自己的位置和尺寸

**外观**
- 三种排版样式（环形 / 网格·六边形 / 网格·矩形）的**宽度·高度·间距·线宽·字高分别保存**，切换互不影响
- 六套配色主题（赛博朋克 / 日式清新 / 蒸汽波 / 莫兰迪 / 黑金 / 8bit），也可跟随 CAD 深浅色
- 矩形网格的宽度与六边形共用，只单独配高度

**配置**
- 存在 DLL 同目录的 `蜂窝面板.json` 里
