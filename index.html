安装

  1. 下载上面的 HoneyPanel.dll，放进任意目录（没有固定路径要求，自己能找到就行）。
  2. 在 CAD 里输入 NETLOAD，选中这个文件。命令行出现「蜂窝面板独立插件已加载」即成功。
  3. 按 Ctrl + 中键 呼出面板。

NETLOAD 一次就写入自动加载，以后开 CAD 自动带出来。选定一个目录后别再挪动——配置文件 蜂窝面板.json 按 DLL 所在目录读写，换了目录等于换一套配置。

操作

Ctrl + 中键呼出面板（快捷键可在设置窗里改）
面板中心「设置」钮打开设置窗，改布局、外观、呼出方式和按钮命令
HONEYUNLOAD卸载：删自动加载键 + 写禁用标记 + 摘钩子 + 关面板。重启 CAD 后彻底退出；重新启用用 HONEYENABLE
HONEYENABLE删除禁用标记，重新挂载呼出钩子（DLL 已在当前进程时立即生效）
功能

布局

  • 环形蜂窝：六边形绕圈排布，三形态（隐藏 / 常驻面板 / 常驻中心），隐藏时靠 Ctrl+中键呼出
  • 网格条：横向排列，恒常驻，不占呼出快捷键
  • 设置窗里随时切换，两种布局各自记住自己的位置和尺寸

外观

  • 三种排版样式（环形 / 网格·六边形 / 网格·矩形）的宽度·高度·间距·线宽·字高分别保存，切换互不影响
  • 六套配色主题（赛博朋克 / 日式清新 / 蒸汽波 / 莫兰迪 / 黑金 / 8bit），也可跟随 CAD 深浅色
  • 矩形网格的宽度与六边形共用，只单独配高度
